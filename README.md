# 📚 Web Scraping — Books Data

## 📌 Project Overview

This project is a Python-based **Web Scraping project** that collects book information from multiple HTML pages.

The project uses **Requests** to access web content and **BeautifulSoup** to parse HTML and extract the required book information. 
The collected data is then processed and organized using **Python and Pandas**.

The main purpose of this project is to understand how web data can be collected, extracted, processed, and prepared for further analysis.

## 🎯 Objectives

- Collect book information from web pages.
- Process multiple HTML pages.
- Parse HTML content using BeautifulSoup.
- Extract required book information.
- Store extracted information using Python data structures.
- Combine data collected from multiple pages.
- Organize and process the collected data using Pandas.
- Understand the basic workflow of web scraping.
